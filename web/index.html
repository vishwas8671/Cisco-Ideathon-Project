SmartBranch 360 enforces Cisco network reliability through a cyclical verification pattern:

  • BUILD: Construct secure topology design in Cisco Packet Tracer.
  • BREAK: Seed intentional faults in the switch and router configuration.
  • DIAGNOSE: Use our custom Python Assurance tool to automatically locate faults in log dumps.
  • FIX: Apply the suggested Cisco CLI repair commands.
  • VERIFY: Rerun connectivity and audit checks to prove compliance.

DHCP & DNS Network Infrastructure Services

  • DHCP Pools Scope (Router-hosted):
    • EMPLOYEE_POOL: network 10.10.10.0/24, gateway 10.10.10.1, DNS 10.10.30.10, leases 10.10.10.10 - .250 (IPs .1-.9 excluded).
    • GUEST_POOL: network 10.10.20.0/24, gateway 10.10.20.1, DNS 10.10.30.10, leases 10.10.20.10 - .250 (IPs .1-.9 excluded).
    • MANAGEMENT_POOL: network 10.10.99.0/24, gateway 10.10.99.1, DNS 10.10.30.10, leases 10.10.99.10 - .50 (IPs .1-.9, .51-.254 excluded).
  • Internal DNS Configuration (Server SRV-DNS-WEB - 10.10.30.10):
    • A-record mapping: dns.smartbranch.local → 10.10.30.10
    • A-record mapping: server.smartbranch.local → 10.10.30.10
    • Compliance Note: Allow UDP port 53 traffic from both Employee and Guest VLANs to DNS server 10.10.30.10. Although Guests are blocked from general server subnet access, they must be allowed to make DNS queries for domain name resolution.

WAN Uplink & NAT/PAT Configurations

Inside private subnets (VLANs 10, 20, 99) share a single public IP address on Router R1's GigabitEthernet0/0 interface to access the internet using NAT overload (Port Address Translation).

  • Outside NAT Interface: GigabitEthernet0/0 (IP: 203.0.113.2/30, Lab WAN IP)
  • Inside NAT Interfaces: R1 sub-interfaces Gi0/1.10, Gi0/1.20, Gi0/1.30, Gi0/1.99
  • NAT ACL Mapping: Standard ACL NAT_ACL permits subnets 10.10.10.0/24, 10.10.20.0/24, and 10.10.99.0/24.
  • Cisco Overload Instruction: ip nat inside source list NAT_ACL interface GigabitEthernet0/0 overload translates port addresses to allow concurrent internet connections.
  • Default Routing: Router R1 points to ISP Gateway 203.0.113.1 via: ip route 0.0.0.0 0.0.0.0 203.0.113.1.

Python CLI Configuration Assurance Utility

We designed and programmed an automated Python script validator.py that runs locally in your terminal. It reads parsed console logs and validates them against the design constraints defined in smartbranch360.yaml.

Features:

  • Parses configuration logs dynamically.
  • Audits SVI subnet settings, VLAN entries, and router subinterfaces.
  • Scans allowed trunk VLAN IDs and flags missing trunk configurations.
  • Evaluates ACL permit/deny statements and rules execution order.
  • Checks for SSH administration line access-class limitations.
  • Validates WAN subinterfaces and NAT overload (PAT) status.

How to Execute:

# Run against healthy configuration
python python-validator/validator.py --config python-validator/sample_config.txt

# Run against a fault scenario
python python-validator/validator.py --config python-validator/sample_faults/fault_wrong_gateway.txt

Cisco Project Implementation Phases

1
Design & Blueprint (PLAN)

Specify subnets, VLAN mappings, DHCP ranges, inside/outside NAT guidelines, and ACL security policies in smartbranch360.yaml.

2
Topology Assembly (BUILD)

Construct the network layout in Cisco Packet Tracer following the Port Connections Map. Assign interfaces, encapsulation, and SVIs.

3
Connectivity Baseline (TEST)

Confirm clients receive DHCP parameters, local DNS queries resolve, and NAT translates packets outwards while ACL rules block guest leaks.

4
Fault Injection (BREAK)

Inject intentional misconfigurations into the active devices (e.g. disable a VLAN on a trunk link or mess up the VTY line ACL).

5
Assurance Check (DIAGNOSE)

Copy CLI dumps and execute the Python script to run static assertions. Identify the misconfigured parameter and root cause.

6
Apply Remediation (FIX)

Paste the suggested Cisco IOS configuration commands back into the switch/router CLI to restore compliance.

7
Post-fix Audit (VERIFY)

Re-evaluate log outputs. Confirm that there are 0 findings and all verification connectivity test cases return to PASS.
